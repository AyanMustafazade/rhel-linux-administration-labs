# RHEL Linux Administration Labs

A collection of hands-on Red Hat Enterprise Linux (RHEL) system
administration labs covering core Linux administration, networking,
storage, security, services, and troubleshooting.

## 🛠 Technologies & Tools

- Red Hat Enterprise Linux (RHEL)
- Bash / Linux CLI
- systemd & systemctl
- NetworkManager / nmcli
- LVM
- SSH
- Firewalld
- SELinux
- Apache HTTP Server
- Cron
- ACL

## 📚 Topics Covered

### 👤 User & Group Management
- User and group creation
- UID/GID management
- Password policies
- sudo and sudoers configuration
- Login restrictions

### 🔐 Permissions & Access Control
- Standard Linux permissions
- chmod / chown / chgrp
- SUID, SGID and Sticky Bit
- Access Control Lists (ACL)
- Collaborative directories

### 🌐 Linux Networking
- Static and dynamic IP configuration
- NetworkManager and nmcli
- Default gateway configuration
- DNS configuration
- Secondary IP addresses
- Connectivity troubleshooting

### 💾 Storage Management
- Disk partitioning
- Filesystem creation
- Mounting filesystems
- Persistent mounts
- LVM
- Physical Volumes (PV)
- Volume Groups (VG)
- Logical Volumes (LV)

### ⚙️ System Administration
- Process management
- systemd services
- Cron jobs
- Package management
- Log analysis
- File searching and archiving

### 🌍 Web Server Administration
- Apache HTTP Server
- Virtual Hosts
- Port-based hosting
- Firewall configuration
- SELinux configuration
- Web server log management

### 🛡 Security
- SSH configuration
- Firewalld
- SELinux
- sudo privilege restrictions
- SUID/SGID management
- ACL-based access control

## 🎯 Objective

The objective of these labs is to develop practical Linux system
administration skills through hands-on configuration,
troubleshooting, security, networking, and server management tasks.
