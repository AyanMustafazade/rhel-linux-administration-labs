# Enterprise Linux, DevOps & Automation Project

## Project Overview

This project demonstrates the design, configuration, automation, and
security assessment of an enterprise Linux and DevOps infrastructure.

The project was completed as part of a 21-day Enterprise IT /
Cybersecurity Sprint in the role of Linux & DevOps Engineer.

## Technologies & Tools

- Red Hat Enterprise Linux 9
- Linux CLI / Bash
- SSH
- Firewalld
- Chrony / NTP
- Cron
- LVM
- Apache HTTP Server
- Docker Engine
- Docker Compose
- NGINX Reverse Proxy
- SSL/TLS
- Ansible
- Wazuh Agent
- Nmap
- Nikto

## Project Implementation

### RHEL 9 Server Administration
- Static IP and hostname configuration
- SSH configuration
- Firewalld configuration
- Time synchronization with Chrony
- Cron job configuration
- LVM storage management
- Apache web server deployment

### Docker & Containerization
- Docker Engine installation
- Docker Compose configuration
- Containerized web application deployment
- Persistent Volume configuration
- Container testing and troubleshooting

### NGINX Reverse Proxy & Web Security
- NGINX Reverse Proxy configuration
- HTTP to HTTPS redirection
- SSL/TLS configuration
- Security Headers
- Rate Limiting
- Backend integration

### Infrastructure Automation with Ansible
- Ansible Control Node configuration
- Inventory management
- User Management playbook
- Package Update playbook
- Service Management playbook
- SSH Hardening automation
- Docker installation automation
- Wazuh Agent deployment automation

### Security Assessment
- Nmap network and service scanning
- Nikto web security scanning
- Security findings analysis
- Risk assessment
- Mitigation recommendations
