# RHEL System Administration

Hands-on Red Hat Enterprise Linux (RHEL) labs covering essential system administration tasks, system configuration, services, filesystem structure, and administrative commands.

## Skills Practiced

- Linux filesystem structure
- System information and hostname management
- User and system configuration files
- Service management with systemd
- Package management
- Date and time configuration
- System monitoring
- Administrative command-line operations
- Linux configuration files
- Basic troubleshooting

## Practical Areas

### Linux Filesystem

Worked with important Linux directories and system configuration files.

```bash
ls /
cat /etc/passwd
cat /etc/group
cat /etc/sudoers
```

### System Information

Practiced retrieving and modifying system information.

```bash
hostname
hostnamectl
uname -a
```

### Service Management

Managed Linux services using systemd.

```bash
systemctl status <service>
systemctl start <service>
systemctl stop <service>
systemctl restart <service>
systemctl enable <service>
```

### System Monitoring

Used Linux administrative commands to inspect system state and resources.

```bash
uptime
free -h
df -h
```
